TWO YEARS OF US

Open index.html in any browser. Keep it next to the photos and videos folders.

To add a photo: put the picture in the photos folder, then open index.html in a text editor
(Notepad or TextEdit), find the list that starts with  var MEDIA=[  and copy one line, e.g.
  {type:'image',src:'photos/NEW-PHOTO.jpg',r:0.75,caption:'Your caption'},
r is width divided by height (0.75 for a normal portrait photo, 1.5 for a normal landscape one).
To change a caption or a reason, edit the text between the quotes.
Easier: send the new files to Claude and it will do all of this for you.
